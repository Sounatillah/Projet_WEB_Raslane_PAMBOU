# The Last Message — Dossier n°017

**Élise Moreau a disparu. Un dernier message, plusieurs documents et quatre suspects : à vous de reconstituer les faits.**

The Last Message est un site narratif qui présente une enquête fictive à travers les pages d’un dossier. Le visiteur découvre l’affaire, examine les éléments disponibles et est invité à confronter les témoignages.

## Pages du site

- **Accueil** — présente l’enquête et invite à ouvrir le dossier.
- **L’affaire** — raconte la disparition d’Élise Moreau et présente son dernier message.
- **Les preuves** — résume les documents, les suspects et les étapes de l’enquête.
- **À propos** — page prévue dans la navigation pour présenter le projet.

## L’histoire

Le dernier contact d’Élise Moreau date du **17 octobre 2026 à 23 h 47**. Son message dit :

> « J’ai trouvé la preuve. Dossier 17. Si quelque chose m’arrive, ne crois pas ce qu’ils diront. »

Six documents et quatre suspects sont au cœur de l’enquête. Le visiteur est invité à examiner les preuves, comparer les témoignages et tirer sa propre conclusion.

## Technologies

- HTML5
- CSS3
- Mise en page adaptative pour les écrans mobiles
- Aucune bibliothèque externe nécessaire

## Lancer le site

1. Clonez ou téléchargez le dépôt.
2. Ouvrez `accueil.html` dans un navigateur.

Pour travailler avec un serveur local, vous pouvez aussi ouvrir le dossier dans VS Code et utiliser l’extension **Live Server**.
